# 932321.Makhneva.Maria.lab1

## Лабораторная работа №1. HTML-страница «О себе».

### Описание работы

Создана HTML-страница «О себе», посвящённая теме **«Искусство и креатив»** (Вариант 4). Страница демонстрирует базовую структуру HTML-документа, использование семантических тегов, работу с текстом, списками, изображениями и формой обратной связи.

### Структура страницы
  
**`<header>`** – шапка с заголовком страницы, фамилией и именем студента, фотографией профиля.  
**`<img>`** – изображение: фотография профиля.  
**`<main>`** – основной контент – две секции:  
  **`<section>`**: «Навыки» (маркированный список) из 4 пунктов.  
  **`<section>`**: «Проекты» (нумерованный список) из 3 пунктов.  
**`<aside>`** – боковая панель с краткой информацией о любимом направлении в искусстве.  
**`<form>`** – форма обратной связи с полями: имя, email, сообщение.  
**`<footer>`** – подвал с копирайтом и годом.
